# メモリアルメッセージ 投稿ページ

スマホの投稿画面（文字の投稿と音声入力）です。会場の投稿用QRから開きます。GASの画面に出る注意書きを避け、スマホのマイクを使えるよう、GitHub Pagesで配信しています。

- このページには合言葉・APIキー・投稿は入っていません。案件と接続先は、QRのURLの「#」以降でだけ受け取ります。
- 確認・保存・文字起こし・要約・修正は、すべて案件のGAS（投稿用の合言葉で確認）が行います。
- 元のソース：非公開リポジトリ kyosodo-memorial-message の `post-page/index.html`。こちらは公開用のコピーです。直接編集せず、元を直してからコピーします。
