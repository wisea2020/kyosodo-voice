# メモリアルメッセージ 音声入力ページ

スマホの投稿画面の「声で入力」から開く録音ページです（GASの画面の中ではスマホのマイクが使えないため、GitHub Pagesで配信しています）。

- このページには合言葉・APIキー・投稿は入っていません。案件と接続先は、投稿画面から渡されるURLの「#」以降でだけ受け取ります。
- 文字起こし・要約・修正・送信は、すべて案件のGAS（投稿用の合言葉で確認）が行います。
- 元のソース：非公開リポジトリ kyosodo-memorial-message の `voice-page/index.html`。こちらは公開用のコピーです。直接編集せず、元を直してからコピーします。
